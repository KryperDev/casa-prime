# \# 🏠 Casa Prime

# 

# \*\*Gerenciamento Financeiro Familiar\*\*

# 

# O Casa Prime é um aplicativo mobile completo desenvolvido em Flutter, projetado especificamente para famílias que desejam organizar, compartilhar e acompanhar suas finanças de forma simples, transparente e segura.

# 

# > \*\*Criado por Anderson Scantamburlo\*\*

# 

# \---

# 

# \## 📱 Sobre o Aplicativo

# 

# Diferente de aplicativos de finanças individuais, o \*\*Casa Prime\*\* permite que múltiplos membros da mesma família participem de uma única conta compartilhada. Cada membro tem seu próprio acesso, mas todos visualizam e contribuem para o mesmo ecossistema financeiro.

# 

# \### ✨ Principais Funcionalidades

# 

# \- \*\*👨‍👩‍👧‍👦 Multiusuário:\*\* Crie uma família e convide membros via código.

# \- \*\*🔐 Permissões:\*\* Administradores gerenciam a família; membros lançam e visualizam.

# \- \*\*💰 Lançamentos:\*\* Registre entradas e saídas com categoria, conta, forma de pagamento e autor.

# \- \*\*🎯 Metas Financeiras:\*\* Crie objetivos e guarde dinheiro com lançamento automático.

# \- \*\*🔄 Recorrências:\*\* Cadastre salário, aluguel, assinaturas uma vez e o app lança todo mês.

# \- \*\*💳 Parcelamento:\*\* Divida compras de cartão em até 24x automaticamente.

# \- \*\*📊 Relatórios:\*\* Gráficos interativos mensais e anuais (Entradas x Saídas, Gastos por Categoria).

# \- \*\*📤 Exportação:\*\* Gere relatórios em PDF e CSV para compartilhar.

# \- \*\*🌙 Tema:\*\* Modo claro e escuro com sincronização.

# \- \*\*🔔 Notificações:\*\* Alertas no app quando membros criam ou alteram lançamentos.

# \## 🛠️ Tecnologias Utilizadas

# 

# \- \*\*Framework:\*\* Flutter / Dart

# \- \*\*Banco de Dados:\*\* Firebase Cloud Firestore (Tempo real)

# \- \*\*Autenticação:\*\* Firebase Auth (E-mail/Senha)

# \- \*\*Armazenamento:\*\* Cloudinary (Fotos de perfil)

# \- \*\*Estado:\*\* Bloc / Provider

# \- \*\*Gráficos:\*\* fl\_chart

# \- \*\*Exportação:\*\* pdf, printing, share\_plus

# \- \*\*Arquitetura:\*\* Clean Architecture (separação por features)

# \## 📥 Como Instalar (APK)

# 

# 1\. Acesse a aba \*\*\[Releases](../../releases)\*\* deste repositório.

# 2\. Baixe o arquivo `app-release.apk` da versão mais recente.

# 3\. No celular Android, permita a instalação de aplicativos de fontes desconhecidas.
